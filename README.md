# DecoPlantas

Sitio web para mostrar plantas decorativas para el hogar.

## Estructura

- `index.html`: Página principal.
- `assets/css/style.css`: Estilos externos.
- `assets/img/`: Carpeta para imágenes.

## Cómo agregar imágenes

1. Coloca tu imagen del encabezado en `assets/img/` y nómbrala `fondo.jpg`.
2. Coloca tus imágenes de plantas como `planta1.jpg`, `planta2.jpg`, y `planta3.jpg`.
3. Asegúrate de que las rutas en `index.html` coincidan con los nombres de las imágenes.

## Sugerencia de ramas Git

- `main`: versión funcional del sitio.
- `estilos`: desarrollo del diseño CSS.
- `productos`: edición de imágenes y textos de productos.
